# Python Log Parser

A Python script that reads large, messy text files line by line 
using generators for memory efficiency, extracts patterns using 
regex, and flags anomalies in the data.

## Skills Demonstrated
- File handling with context managers (with open())
- Regular expressions (regex) for pattern matching
- Generators for memory-efficient processing (O(1) space)
- Data validation and anomaly detection
- Exception handling for malformed data

## Technologies
- Python 3
- re (regex)
- Generator functions

## How to Run
```bash
python log_parser.py
```
